# Contributing to NEXORA

Thank you for your interest in Nexora. Keep contributions focused, transparent, and technically useful.

## Guidelines

1. Open an issue before substantial changes.
2. Do not publish unverified token, reward, partnership, or performance claims.
3. Keep code, documentation, and examples reproducible.
4. Use clear commit messages and include testing notes in pull requests.

## Pull Requests

Please describe the problem, the proposed change, validation performed, and any follow-up work.
